# Process

> [!NOTE]
> All my 100% human commentary will be in these formatted note blocks.
>
> I've been using AI productively since before it was cool, and over the last few years I've done
> things I wouldn't have had the time of day for before the current state of AI.
>
> When I saw the original
> [Reddit post](https://www.reddit.com/r/LaTeX/comments/1xixznw/how_do_you_make_these_flowers_in_latex/),
> I thought it would be a good opportunity to try out something that I'm not very familiar with
> (LaTeX and Lua) and without any initial grounding materials (i.e., no source code). Having no
> source should have made it easier to not make a direct copy, but you'll see that's exactly where
> Claude started.
>
> The original planning and release took about three hours. I used Claude.ai for planning (Fable 5.1,
> Extra effort) and Claude Code for implementation (Opus 5.5, xhigh effort).
>
> I mentioned in a Reddit comment that I would post the process I used, so this is it. I split it
> into two files because I started with Claude.ai (browser) and ended with Claude Code (CC). I used
> CC to help create these MD documents from the Claude.ai copy/paste and artifacts, and CC's session
> logs. This process goes through the v1.0 release tag; I've done some more work since then, but I wanted to stop at the
> version I originally shared. Little did I know this would have such a following, and someone even
> dropped it on Hacker News.
>
> Whichever side of the AI line you stand on, I respect your opinion - thanks for allowing me to
> share something that reflects mine.
